#  🔗 Link Shield

Link Shield is a dApp (decentralized application) designed to create traceable, protected links using Web3 technology.

<p>
     <a href="https://linkshield.viniciuspesqueira.dev/">📱 Visit this Project</a>
</p>

<br>

## How it's works?

  1. [Download](https://metamask.io/pt-BR/download) Metamask Wallet in your browser or smartphone;
  2. Add the URL to be protected;
  3. Defines the fee per click(in wei);
  4. Connect your Metamask Wallet to the web application;
  5. Copy the generated protected link.

<br>

## 💻 Technologies
  - [Metamask](https://metamask.io/pt-BR);
  - [Next.js](https://nextjs.org/);
  - [React.js](https://react.dev/);
  - [Web3.js](https://web3js.readthedocs.io/en/v1.10.0/)
  - [BNB Chain](https://www.bnbchain.org/en);
